Native HAT / DAT / SUPIR backend
--------------------------------
The optional backend installs PyTorch, torchvision, spandrel, ONNX Runtime and
their dependencies from PyPI. Those packages keep their own licenses. SUPIR
also depends on the upstream SUPIR repository and an SDXL base checkpoint,
which are downloaded separately by the user.

Video upscaling
---------------
Video upscaling uses FFmpeg from the user's PATH. FFmpeg is not bundled with
Upscayl-Next; its license depends on the FFmpeg build in use.

Application framework
---------------------
Upscayl-Next is built with Electron, Chromium and Node.js. Their license files
are included in the packaged application by electron-builder.
